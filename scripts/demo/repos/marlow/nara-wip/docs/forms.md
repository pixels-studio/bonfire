# Forms

Label every field. Placeholder text is a hint, not a label.

## Validation

Validate on blur, then on every change once a field has been marked invalid.
Show the message under the field, in `--danger`, and move focus to the first
invalid field when a submit fails.

## Layout

Stack fields in one column. Put a short, related pair (city and postcode)
side by side only above 640 px.
