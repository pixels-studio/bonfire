# Buttons

Use a button for an action. Use a link for navigation.

## Variants

- **Primary**: one per view, for the main action.
- **Secondary**: supporting actions.
- **Ghost**: low-emphasis actions, such as Cancel.

## Sizes

Buttons come in `sm` (28 px), `md` (36 px) and `lg` (44 px). Touch targets
must be at least 44 px, so use `lg` on mobile.
