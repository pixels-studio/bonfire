# Colors

Marlow uses a neutral scale and one accent. Every pair listed here meets
WCAG AA contrast (4.5:1 for body text).

| Token            | Light     | Dark      |
| ---------------- | --------- | --------- |
| `--surface`      | `#ffffff` | `#141414` |
| `--text`         | `#1a1a1a` | `#f2f2f2` |
| `--accent`       | `#d9480f` | `#ff7a3d` |
